Como usar

  1. Clique em uma parte do logo ou em um dos botões abaixo.
  2. Escolha uma cor pronta ou ajuste manualmente.
  3. Clique na próxima parte que quiser alterar.
  4. Gostou? Clique em Guardar combinação para comparar depois.
  5. Use Copiar cores para enviar os códigos, ou Baixar logo em PNG.
